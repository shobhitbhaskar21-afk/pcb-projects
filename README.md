# PCB Design Projects

This repository showcases four PCB design projects developed using **Altium Designer**.

## Projects

1. **ESP32 Power Management PCB** – ESP32-based power supply and distribution board.
2. **Arduino RTC Data Logger PCB** – Arduino-based data logging system integrating RTC, OLED, and SD card.
3. **Sensor Integration PCB** – Multi-sensor interfacing and monitoring board.
4. **4-Channel Relay Control PCB** – Relay-based control board for switching multiple electrical loads.

## Tools Used
- Altium Designer
- PCB Schematic Capture
- PCB Layout and Routing
- Electronic Component Integration

## How to Open
1. Download the required project ZIP file.
2. Extract the ZIP archive.
3. Open the schematic (`.SchDoc`) or PCB layout (`.PcbDoc`) files using Altium Designer.
